# Snake (Console Game)

## Description
This is a classic Snake game implemented as a C# console application.  
The gameplay recreates the traditional mechanics where the player controls a snake that grows longer each time it eats an apple.

---

## Concept and Implementation
Apples are randomly generated on the game field, and the player must collect them while avoiding collisions with the walls or the snake’s own body.  
Each apple increases the snake’s length and the score counter.  
The game ends when the snake hits a wall or itself.

---

## Main Features
- Random apple generation  
- Movement control using keyboard arrow keys  
- Collision detection with walls and the snake’s body  
- Real-time score counter  
- Clean and simple console interface

---

## Technologies Used
- Language: C#  
- Type: Console Application
